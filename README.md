# The Bar 🍸

A clean, luxury cocktail menu website for your personal drinks, designed to be hosted on **GitHub Pages**.

---

## 🍹 Menu Highlights
- **Old Fashioned** *(Bourbon / Rye Whiskey, Demerara Syrup, Bitters)*
- **Manhattan** *(Rye Whiskey, Sweet Vermouth, Bitters)*
- **Rob Roy** *(Blended Scotch Whisky, Sweet Vermouth, Bitters)*
- **Whiskey Sour** *(Bourbon, Fresh Lemon, Simple Syrup, Egg White)*
- **Sparkling Whiskey Sour** *(Bourbon, Fresh Lemon, Simple Syrup, Sparkling Club Soda)*
- **Whiskey Highball** *(Whiskey, Sparkling Club Soda, Expressed Lemon)*
- **Tom Collins** *(London Dry Gin, Fresh Lemon, Simple Syrup, Sparkling Club Soda)*
- **Negroni** *(London Dry Gin, Campari, Sweet Vermouth)*
- **The Gimlet** *(London Dry Gin, Fresh Lime, Simple Syrup)*
- **Spanish Gin & Tonic** *(London Dry Gin, Chilled Tonic Water, Lime)*

---

## 💡 Features
- **High-End Speakeasy Aesthetic**: Deep obsidian background with warm gold typography (`Cinzel` & `Cormorant Garamond`).
- **Interactive Drink Cards**: Filter by base spirit (*Bourbon, Rye, Scotch, Gin*) and flavor profile (*Spirit-Forward, Citrus, Crisp, Rich*).
- **Instant Search**: Find cocktails quickly by name or ingredient.
- **Recipe Specs Modal**: View measurements with an instant **oz / ml toggle**, ice and glassware specs, and step-by-step preparation instructions.
- **Zero Build Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript. Fast, lightweight, and works out of the box.

---

## ✏️ How to Add or Edit Cocktails
All cocktail recipes and details are neatly organized in [`js/drinks.js`](js/drinks.js). To add a new drink or adjust measurements, simply edit that file!

## 🚀 Deploying to GitHub Pages
1. In your terminal:
   ```bash
   cd /Users/sunsfz/TheBar
   git init
   git add .
   git commit -m "Initial commit of The Bar"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. On GitHub, go to your repository's **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website is live!
